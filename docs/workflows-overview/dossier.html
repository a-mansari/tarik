Tarik - Dossier

Opens a new client file (dossier) in Experio, optionally copies another file's setup, imports the client's accounting history (FEC or general ledger), finishes the onboarding and reports where the file stands. Also loads a FEC into an existing file.

Started byThe AI agent (Experio_parametrer_dossier), or Tarik - Emails following up.
Time budget260 seconds. When Experio's wait would not fit, the file is left waiting and the email follow-up finishes it.
Ends withA summary: creation, import, onboarding and the file's state.

The workflow in n8n

Each box is a node, named exactly as in n8n's editor and placed where it sits there. Lines show where each node leads.

Starting a run

Appel

The call: the conversation, the client file (0 for a new one), its name, ICE, IF, company or person, the file whose setup to copy, FEC or general ledger, the attachments, the firm.

Debut

Notes when the run started, for its time budget.

Pieces jointes de l'agent

Saves files attached in n8n's chat.

Nouveau dossier ?

A new client file, an existing one, or a follow-up.

A new client file

Creation (create_dossier)

Creates the file as Experio's Folders screen does. Experio checks the name is free and the ICE and IF against the official register. A very similar name, or skipping the register check, is confirmed with the client first.

Suite apres create_dossier

Created: on to the next step. A question or a refusal: recorded, and the run stops there.

Modele ?

Copy another file's setup only if the client asked for it.

Configuration (copy_configuration)

Copies that file's accounts, taxes, journals, bank operations and settings, before any import.

Suite apres copy_configuration

Copied: on to the import. Otherwise recorded, and the run stops.

An existing client file

Expediteur (check_sender)

The email's sender must be one of the firm's staff, or of Experio's own team, with this client file assigned.

Suite apres check_sender

Allowed: on to the import. Otherwise the run stops.

Importing the history

Dossier cible

The client file the rest works on: the one given, or the one just created.

Fichiers du message (files_to_process)

The conversation's FEC and general ledger files not imported yet.

Un element par fichier

One item per file.

Ecritures (import_entries)

Imports the entries through Experio's Importation screen, after Experio's own test of the file. Experio creates the missing accounts, journals, suppliers, customers and fiscal years. A refused file is reported; the client sends a corrected one.

Finishing the onboarding

Imports acceptes ?

Only when no import was refused.

Integration (finish_setup)

Completes Experio's onboarding steps so Experio processes the imported entries, opening the current fiscal year if none is open. Experio only takes lines once they are a minute old: when that wait does not fit in the run's time, the file is left waiting for the follow-up.

Integration terminee ?

Finished: read the file's state. Left waiting: its state comes with the follow-up.

Etat du dossier (setup_status)

Where the file stands: imported entries by state, fiscal years, and any setting Experio needs before an invoice can be posted.

Following up

Only when Tarik - Emails follows up a thread.

Integrations en attente (waiting_setups)

The conversation's client files whose entries were imported and whose onboarding still waits.

Un element par dossier

One item per file.

Integration reprise (finish_setup)

Finishes the onboarding, with no time limit.

Reprise terminee ?

Finished: read the file's state.

Etat du dossier repris (setup_status)

Where the file stands, for the follow-up email.

Recording and answering

Enregistrer

Records every step's outcome.

Resume

Runs last: the run's summary, which the agent copies.
