Tarik, the bookkeeping assistant for accounting firms

Clients email Tarik their invoices, bank statements and accounting exports. Tarik records them in Experio, the firm's accounting software, and replies in the same email thread. An AI agent understands each request; four fixed workflows in n8n do the work.

The AI never writes to Experio itself. It reads the request, picks a workflow and fills in a few fields (which client file, purchase or sale). Every write goes through fixed, tested steps, and each step's result is recorded, so nothing is invented and everything can be traced.

Front door

Tarik - Emails

Answers the firm's mailbox.

  1. The mail watcher files each new email into its thread and saves the attachments.
  2. Only the firm's own staff, registered in Experio, are answered, and only at approved addresses. Anyone else is ignored and the manager is told.
  3. A new conversation gets an instant reply: the message is received and Tarik answers in a few minutes.
  4. The firm's AI agent reads the email and calls the right workflow.
  5. The answer goes back as a reply in the same thread.
Every step of Tarik - Emails →

Follow-up email. When Experio is still working (reading a scan, taking in imported entries), Tarik replies with what is done, then sends the rest a few minutes later in the same thread. The client does not have to ask again.

Invoices and bank statements

Tarik - Traitement

Turns the attached documents into posted entries in Experio.

  1. Identify each file: invoice or bank statement.
  2. A bank statement is imported into the client file's bank account.
  3. An invoice PDF is split if it holds several, and each becomes a draft in Experio.
  4. Wait for Experio's own reading (OCR) of the draft.
  5. Check and correct what was read; purchase or sale; supplier; duplicates; account (e.g. 6125); VAT; journal; withholding tax; prepaid; fiscal year.
  6. Post the invoice.
Every step of Tarik - Traitement →

When it needs the client, it asks one clear question marked “QUESTION :”. The client answers by email and processing continues from that exact step.

New client file

Tarik - Dossier

Opens a client file in Experio, or loads past accounting into one.

  1. Create the file. Experio checks the name is free and the ICE and IF against the official register; a very similar name is confirmed with the client first.
  2. Copy another file's setup (chart of accounts, settings), only if the client asks.
  3. Import the history the client attached: a FEC or a general ledger. Experio creates the missing accounts, journals, suppliers, customers and fiscal years.
  4. Finish the onboarding. Experio only takes lines once they are a minute old, so this step waits.
  5. Report the file's state: accounts, journals, entries, open fiscal years.
Every step of Tarik - Dossier →

Large imports that cannot finish in time are completed by the follow-up email, which also sends the file's state.

Changing a client file

Tarik - Modification

Updates an existing file's details: name, type, ICE, IF, RC, patente, T.S.C, capital, CNSS, address.

  1. Check the sender is allowed to work on that client file.
  2. Change only the fields the client asked for, to the values the client wrote. The AI cannot fill in or “correct” a value.
  3. A new ICE or IF is checked against the official register; skipping that check needs the client's explicit confirmation.
Every step of Tarik - Modification →

Short and fast: nothing waits on Experio here.

Built in

  • One firm, one assistant. Several firms share one installation, but each has its own agent, mailbox, data and Experio access. A firm's agent cannot reach another firm's data.
  • Test mode per firm. Drafts are created but nothing is posted. GECAFISC is currently live.
  • No lost or doubled work. A run that fails is retried; after 3 failures the thread is set aside with the reason. A reply is never sent twice, and an interrupted run picks up where it stopped.
  • AI model: MiniMax-M3, about 8 seconds per answer on average.

Current limits

  • 5-minute cap. Each piece of work the AI starts may run up to 5 minutes (raised from n8n's 2). Tarik stops itself in time and finishes anything longer by follow-up email.
  • Experio's reading speed. Scanned invoices can stay unread in Experio for a long time (over an hour in today's test). Tarik handles the wait but cannot speed it up.
  • Email is the main channel. The n8n chat works for testing but takes fewer file types and has no follow-up. WhatsApp could reuse the follow-up later.
