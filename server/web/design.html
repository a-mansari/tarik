Tarik design system

Tokens and components every page is built from. Change a token once, the whole app follows.

Principles

A working tool.

Dense, calm, readable at a glance. A table beats a card grid; an icon beats a sentence when its meaning is clear.

One brand colour.

Green marks what you can act on and where you are. Green, amber and red are statuses only, never decoration.

Tokens, not values.

No raw colour, size or radius in a page. If a token is missing, add it to tokens.css and show it here.

Little text.

A label says what it is. Explanations go in a hover title, never under every field.

Colour

Roles, not shades. Each is a pair (light, dark) defined once with light-dark().
